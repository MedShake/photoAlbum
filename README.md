# photoAlbum

[Français](README.fr.md) | **English**

photoAlbum is a desktop application for composing chronological photo albums from local folders or Synology Photos albums. It lets you correct dates, locations and captions, configure pages and export a PDF. The interface is available in French and English.

**[Full documentation — wiki](https://github.com/MedShake/photoAlbum/wiki)**: installation, usage, templates and development for v0.2.0.
