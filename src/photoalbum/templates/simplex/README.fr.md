# Simplex

**Français** | [English](README.md)

Simplex est un pack de templates intégré à Photo Album, centré sur des mises en page photographiques minimales.

Son fichier `manifest.json` est la source de vérité pour la disponibilité des templates, les types de pages, les positions de couverture et les éventuelles limites physiques de page.

Le pack fournit actuellement un template photographique pleine page utilisable comme couverture à n’importe quelle position ou comme page spéciale, y compris dans le corps de l’album. Son image peut provenir d’une photo du projet ou d’un fichier externe.
